    \subsection{Algorithm}
    The above 4 x 5 grid has a small object in the top-left corner of each grid cell(i.e. node) representing a valid (i.e. rectangle ) or invalid (circle) cell. 
    \begin{itemize}

        \item h - represents horizontal contiguous count. A h=2 means there are h-1 immediate rectangles to the left including the current node
        \item d - represents vertical contiguous count. A d=2 means there are d-1 immediate rectangles to above including the current node
        \item w - represents maximum horizontal width when calculating max area at current node 
        
        
    \end{itemize}
    
    \subsection{Rules}
    \begin{itemize}
        \item $h = $1; max number of rectangles possible at node : d
        \item $d = $1; max number of rectangles possible at node : h
        \item $d \neq 1$ \& $h \neq $1; max number of rectangles possible at node: $w \times $d

    \end{itemize}
